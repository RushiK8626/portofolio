#  Portfolio Website

A minimal and responsive portfolio website showcasing my projects, skills, and professional experience. 

## Live Demo
**[View Portfolio](https://rushikeshkadepurkar.vercel.app/)**

## Tech Stack
Built using modern web technologies:
* **Frontend:** Next.js, Tailwind CSS
* **Hosting:** Vercel

## Local Setup
To run and modify the project on your local machine:

```bash
# Clone the repository
git clone https://github.com/RushiK8626/portofolio

# Navigate to the directory
cd portofolio

# Install dependencies
npm install

# Start the development server
npm run dev
```
